## Live demo · Network isolation

Three curls, three outcomes - allow, deny, default-deny - all decided at the sbx proxy.

```bash terminal-id=demo
curl https://api.anthropic.com -sS -o /dev/null -w "anthropic: %{http_code}\n"
curl https://paste.ee -sS -o /dev/null -w "paste.ee: %{http_code}\n"
curl https://example.com -sS -o /dev/null -w "example.com: %{http_code}\n"
```

## Live demo · Register a server behind the gateway

Point sbx at a real gateway, register a server, and it is proxied behind one governed endpoint.

```bash terminal-id=demo
export SBX_MCP_URL=https://gateway.docker.com
sbx daemon start
sbx mcp add local-wiki --command docker --args "run,-i,--rm,mcp/wikipedia-mcp"
sbx mcp ls
```
